# EcomAgent 修复日志 - 2026-07-04

## 1. 数据库表结构修复

### 问题
- `products` 和 `tiktok_products` 表缺少 `local_image_path` 字段
- 导致图片下载脚本报错 `no such column: local_image_path`

### 修复
- 文件: `scripts/init_all_tables.py`
- 在 `CREATE TABLE` 语句中添加 `local_image_path TEXT` 字段

---

## 2. 跨平台兼容修复

### 问题
- `download_images.py` 的 `print(..., flush=True)` 在某些终端不兼容
- Windows UTF-8 编码问题

### 修复
- 文件: `scripts/download_images.py`
- 添加 Windows UTF-8 兼容处理
- 将 `flush=True` 改为 `sys.stdout.flush()`

---

## 3. TikTok 抓取脚本修复

### 问题
- JavaScript 中 `container` 变量未定义，导致图片、价格无法提取
- 没有提取 `rating` 和 `sold` 字段

### 修复
- 文件: `skills/tiktok-fetcher/src/fetch_tiktok_categories.py`
- 修复 `container` 变量定义
- 添加 `rating` 和 `sold` 字段提取逻辑

---

## 4. 前端 UI 修复

### 问题 1: 系统设置页面编辑字段无法修改
- 原因: `_editField` 和 `_cancelEdit` 方法没有调用 `this.requestUpdate()`
- 修复: 文件 `ui/src/pages/settings.ts`，添加 `this.requestUpdate()`

### 问题 2: 数据抓取卡片勾选类目后按钮状态不刷新
- 原因: `_toggleCategory` 方法没有调用 `this.requestUpdate()`
- 修复: 文件 `ui/src/pages/dashboard.ts`，添加 `this.requestUpdate()`

---
