**方案设计**：
- 抓取时对比历史数据，检测变更
- 在 `daily_sales` 表添加 `name_changed`、`image_changed` 字段
- API 返回事件字段，前端展示为标签

**当前状态**：后端 API 已预留字段，前端已支持展示。待抓取脚本实现变更检测。
