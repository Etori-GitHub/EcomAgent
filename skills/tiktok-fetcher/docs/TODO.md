## 已知问题

### 1. 商品数据提取不完整

**现状**：
- 当前只提取基础信息（名称、价格、评分）
- 缺少销量、评论数、图片 URL 等详细数据

**原因**：
- TikTok Shop 的商品卡片结构复杂
- 需要进一步分析实际页面结构

**解决方案**：
1. 运行脚本，查看实际提取的数据
2. 使用浏览器开发者工具检查商品卡片结构
3. 调整 JavaScript 选择器
4. 提取更详细的数据字段

### 2. 页面加载时间

**现状**：
- 每个分类页面需要 10-30 秒加载时间
- 滚动 5 次，总等待时间约 60-90 秒

**原因**：
- TikTok Shop 页面包含大量图片
- 懒加载导致部分内容需要滚动后才加载

**优化方案**：
1. 使用 `page.wait_for_load_state('networkidle')`
2. 优化滚动策略（只在必要时滚动）
3. 添加加载状态检测

### 3. 反爬机制

**现状**：
- 使用 persistent context 已解决大部分问题
- 但仍可能触发限制

**优化方案**：
1. 增加随机等待时间
2. 添加 User-Agent 轮换
3. 在非高峰时段运行
4. 添加请求频率限制
